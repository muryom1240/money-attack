## 実際の使い方・Unity/UEへの取り込み方：マジで簡単だからビビるな

「そんなアセット、使いこなせるか不安…」って思ったアンタ、心配すんな。小学生でもできるくらい簡単だ。

### Unityへの取り込み方
1.  **アセットストアで購入/ダウンロード**: まずはUnityのアセットストアでこの「街の雑踏コレクション」を検索して購入、ダウンロードするんだ。
2.  **インポート**: プロジェクトウィンドウで右クリック→「Import Package」→「Custom Package...」を選択し、ダウンロードしたパッケージファイルを選択するだけ。これでアセットがプロジェクトに読み込まれる。
3.  **プレハブの配置**: Assets/StreetCrowdCollection/Prefabs/フォルダを開けば、ずらりと並んだキャラクターたちのプレハブが見つかるはずだ。あとはこれをシーンにドラッグ＆ドロップするだけ。マジでこれだけ。
4.  **アニメーションの設定**: 各プレハブにはコントローラーも設定済みだから、あとはスクリプトから`Animator.SetTrigger("Walk")`とか呼び出すだけで、キャラクターが動き出す。細かい調整はUnityのAnimationウィンドウで簡単にできるから、試してみてくれ。

### Unreal Engine 5への取り込み方
1.  **FBXファイルのインポート**: まずダウンロードしたアセットのフォルダにあるFBXファイルを、UE5のコンテンツブラウザにドラッグ＆ドロップする。
2.  **インポートオプション**: 「Import Options」ウィンドウが表示されるから、いくつか設定する。
    *   **Skeletal Mesh**: チェックを入れる。
    *   **Import Animations**: 必要に応じてチェック。今回はアニメーションも使うからONだ。
    *   **Material Import Method**: 「Create New Materials」を選んでおけばOK。
    *   **Texture Import Method**: 「Create New Textures」を選んでおけば、テクスチャもちゃんとインポートされる。
    *   あとは「Import All」で読み込み開始だ。
3.  **マテリアルとテクスチャの確認**: コンテンツブラウザにキャラクターのモデル、スケルトン、アニメーション、そしてマテリアルとテクスチャがインポートされてるはずだ。もしテクスチャがずれていたら、マテリアルエディタで修正してやればいい。ほとんどの場合、そのまま使えるはずだ。
4.  **BPで動かす**: UE5の強みはブループリントだ。キャラクターのメッシュコンポーネントにインポートしたスケルタルメッシュを設定し、アニメーションブループリントを使って動きを制御する。チュートリアル動画もたくさんあるから、それを見ながらやればすぐに慣れるさ。

Blenderで読み込めば、アンタの好き勝手に改造もできる。色を変えるのも、帽子を被せるのも、手足の長さを変えるのも自由自在。既存のアセットをただ使うだけじゃなく、自分だけのオリジナリティを加えることもできるってことだ。
